## 지금 받는 일

**급한 건을 우선 받습니다.** 마감이 임박했거나, 담당자가 없거나,
배포 직전에 문제가 터진 상황이면 당일 착수 가능합니다.

| 작업 | 소요 | 비고 |
|---|---|---|
| 긴급 버그·장애 대응 | 당일~2일 | 원인 특정 후 범위가 커지면 착수 전에 알려드립니다 |
| 중단된 프로젝트 이어받기 | 진단 1일 + 개발 | 진단 리포트만 받고 끝내셔도 됩니다 |
| 랜딩페이지·홈페이지 제작 | 3~7일 | 반응형, 배포, 도메인 연결 포함 |
| 업무 자동화 | 3~5일 | 기존 시스템 위에서 동작하도록 만듭니다 |

## 일하는 방식

- **진행 상황을 매일 공유합니다.** 연락이 끊기는 일은 없습니다.
- **착수 전 확정한 금액 외 추가 청구가 없습니다.** 범위가 바뀌면 작업 전에 상의합니다.
- **완료 후 ⟨2⟩주간 무상 수정.**
- **인수인계 문서를 남깁니다.** 나중에 다른 사람이 이어받을 수 있게 씁니다.
