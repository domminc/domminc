# 엑셀·CSV 취합 자동화

지점별·월별로 흩어진 파일을 하나로 합칩니다.
파일마다 컬럼 이름이 다르고 머리글 위치가 제각각인 상황을 전제로 만들었습니다.

## 왜 만들었나

이 작업을 사람이 하면 파일 20개 기준 40분쯤 걸립니다.
그중 대부분은 컬럼 이름을 맞추고 중복을 찾는 단순 대조입니다.
같은 일을 3초에 끝내고, **무엇이 어떻게 합쳐졌는지 로그로 남깁니다.**
결과를 믿을 수 있어야 자동화가 의미가 있습니다.

## 설치

```
pip install -r requirements.txt
```

## 사용법

```
python merge.py ./입력폴더
python merge.py ./입력폴더 -o 2026년3월_취합.xlsx
python merge.py ./입력폴더 --keep-duplicates
```

하위 폴더까지 훑습니다. `.xlsx` `.xls` `.csv`를 읽고, 엑셀 임시파일(`~$`)은 무시합니다.
**원본 파일은 수정하지 않습니다.**

## 처리하는 것

| 상황 | 동작 |
|---|---|
| 컬럼명이 파일마다 다름 | `거래처명`·`업체`·`고객사` → `거래처`로 통일 |
| 머리글이 1행이 아님 | 위쪽 10행을 훑어 머리글 행을 자동 판별 |
| CSV 인코딩이 섞임 | utf-8 → cp949 → euc-kr 순으로 시도 |
| 숫자에 콤마·"원"이 붙음 | 숫자로 변환 |
| 금액 칸이 비어 있음 | 수량 × 단가로 채움 |
| 같은 거래가 여러 파일에 | 중복 제거 (`--keep-duplicates`로 해제) |
| 관계없는 파일이 섞임 | 경고를 남기고 건너뜀 |

## 결과물

- `취합결과.xlsx` — 합쳐진 데이터. `원본파일` 컬럼으로 출처를 추적할 수 있습니다.
- `merge_log.txt` — 파일별 처리 내역, 제거된 중복 수, 빈 칸 경고, 금액 합계

## 컬럼 추가하기

현장에서 쓰는 표기가 다르면 `merge.py` 상단 `COLUMN_ALIASES`에 넣으면 됩니다.

```python
COLUMN_ALIASES = {
    "거래처": ["거래처", "거래처명", "업체", "고객사", "customer"],
    "담당자": ["담당자", "영업담당", "manager"],   # 이렇게 추가
}
```

띄어쓰기, 괄호, 대소문자는 알아서 무시하므로 `거래처명 (필수)`도 그대로 인식합니다.

## 확인된 동작

머리글이 3행에 있는 엑셀, cp949 CSV, 금액이 빈 파일, 컬럼을 알아볼 수 없는 파일을
섞어 실행했을 때 7행으로 정확히 취합되고 중복 1건이 제거되는 것을 확인했습니다.
