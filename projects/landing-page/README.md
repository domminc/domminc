# 소상공인 랜딩페이지

의존성 없는 단일 HTML 파일입니다. 빌드 도구도, 외부 스크립트도 쓰지 않습니다.

## 왜 이렇게 만들었나

소상공인 페이지는 만든 뒤 **몇 년간 방치되는 게 정상**입니다.
그래서 프레임워크를 쓰면 2년 뒤 빌드가 깨져 손댈 수 없게 됩니다.
파일 하나면 5년 뒤에도 브라우저로 열어 수정할 수 있습니다.

## 특징

- **반응형** — 820px, 720px, 640px에서 레이아웃이 바뀝니다
- **다크 모드** — `prefers-color-scheme` 자동 대응
- **CSS 변수** — 상단 `:root` 6줄만 바꾸면 업종에 맞게 색이 전부 바뀝니다
- **폰트 로드 없음** — 시스템 폰트라 첫 렌더가 즉시 뜹니다
- **시맨틱 마크업** — `<header> <main> <section> <footer>`, 검색 노출에 유리

## 쓰는 법

`index.html`을 열어 텍스트를 바꾸고, 어디든 올리면 끝입니다.
GitHub Pages, Netlify, 카페24 전부 그대로 동작합니다.

색을 바꾸려면 상단만 손대면 됩니다.

```css
:root{
  --accent:#8b4513;   /* 버튼·강조색 */
  --bg:#faf8f5;       /* 배경 */
  --ink:#1c1917;      /* 본문 글자 */
}
```

## 구성

히어로 · 상품 카드 · 클래스 · 영업시간 · 오시는 길 · 푸터.
필요 없는 `<section>`은 통째로 지워도 나머지 레이아웃이 깨지지 않습니다.
