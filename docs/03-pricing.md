# 단가표와 견적 산출

국내 프리랜서 시장의 통상 범위입니다. 협상 기준선으로 쓰세요.

## 작업별 범위

| 작업 | 통상 범위 | 신규 판매자 권장가 |
|---|---|---|
| 긴급 버그·장애 대응 | 30~150만 | 60~90만 |
| 코드 진단 리포트 | 10~30만 | 15만 |
| 랜딩페이지 1p + 배포 | 40~120만 | 60~80만 |
| 반응형 홈페이지 5p | 100~300만 | 130~180만 |
| 업무 자동화 스크립트 | 30~150만 | 50~70만 |
| 크롤러·데이터 수집 | 30~120만 | 50만 |
| 외부 API 연동 | 50~200만 | 80만 |
| 웹앱 MVP | 300~1000만 | 350~450만 |
| 시간제 유지보수 | 시간당 5~15만 | 시간당 8만 |

**목표가 100만원이면 조준할 구간은 60~90만원 1건 + 소액 1건**입니다.
100만원짜리 하나를 정확히 노리는 것보다 성사 확률이 높습니다.

## 가격을 깎지 마세요

신규 판매자가 가장 흔히 하는 실수가 저가 입찰입니다. 역효과가 납니다.

- 시장가의 절반을 부르면 **실력을 의심**받습니다. 저가는 신뢰 신호가 아닙니다.
- 급한 클라이언트는 **가격에 둔감**합니다. 애초에 이들을 노리는 전략입니다.
- 한 번 낮게 부르면 그 클라이언트와의 다음 건도 그 가격에 묶입니다.

깎아야 할 상황이면 **금액 대신 범위를 줄이세요.** "70만원을 50만원으로"가
아니라 "70만원에 5페이지를, 50만원에 3페이지로" 입니다. 시간당 단가를
지키는 게 장기적으로 훨씬 중요합니다.

## 결제 조건

개인 계좌만 있는 상황에서는 조건을 명확히 걸어두는 게 유일한 방어책입니다.

**착수금 30~50%를 받고 시작하세요.** 신규 거래에서 미수금 사고는
대부분 선금 없이 착수한 건에서 납니다. 급한 클라이언트일수록 선금에
저항이 없습니다. 당장 해결되는 게 더 급하기 때문입니다.

거래 전 메시지로 다음 4개를 남겨두세요. 플랫폼 채팅이든 카톡이든
기록이 남는 곳이면 됩니다. 분쟁 시 이게 사실상의 계약서 역할을 합니다.

1. 작업 범위 — 무엇을 하고 무엇을 안 하는지
2. 금액과 지급 시점 — 착수금 비율, 잔금 시점
3. 완료 기준 — 무엇이 되면 끝난 것인지
4. 수정 횟수 — 무상 수정 범위

**72시간 내 입금을 노린다면 플랫폼 에스크로가 아니라 계좌 직거래여야
합니다.** 플랫폼 정산은 완료 후 영업일 단위로 걸립니다. 다만 직거래는
플랫폼 보호를 포기하는 것이라, 선금 조건은 더 중요해집니다.

## 세금

개인 계좌로 받는 프리랜서 소득은 **사업소득**입니다.

- 클라이언트가 사업자면 보통 **3.3% 원천징수** 후 입금합니다.
  100만원 계약이면 실수령 96.7만원입니다. **목표가 실수령 100만원이면
  103.5만원으로 계약**해야 맞습니다.
- 개인 클라이언트면 원천징수 없이 전액 입금되고, 다음 해 5월
  종합소득세 신고 때 본인이 신고합니다.
- 연 매출이 늘면 사업자등록이 유리해지는 구간이 옵니다.
  지금 단계에서는 필요 없습니다.

정확한 판단은 세무 전문가 영역입니다. 위 내용은 일반적인 구조 설명이고,
금액이 커지면 확인받으세요.
