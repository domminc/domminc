# 트랙 A — 자산 현금화

72시간 100만원을 **실제로 맞출 확률이 가장 높은 경로**입니다.
당신 시간 1시간, 개인 계좌 즉시 입금, 플랫폼 정산 지연 없음.

"버는 것"이 아니라 "현금화"라 원하신 답이 아닐 수 있습니다. 다만 유입 채널
없음 · 가용 시간 5시간 이하라는 조건에서 기한 안에 목표를 맞추는 경로는
현실적으로 이것뿐이라, 트랙 B와 병행하시길 권합니다.

## 100만원을 만드는 조합

한 개로 끝내는 게 시간 대비 가장 효율적입니다. 거래 1건은 응대 30분이지만
5건은 2시간 반입니다. **고가 소수**로 가세요.

| 품목 | 중고 시세대 |
|---|---|
| 노트북 (맥북 계열 최근 모델) | 70~150만 |
| 미러리스·DSLR 바디 + 렌즈 | 50~150만 |
| 아이패드 상위 모델 | 40~80만 |
| 스마트폰 (안 쓰는 예전 기기) | 20~60만 |
| 모니터 27인치 이상 | 15~40만 |
| 태블릿·이북리더·스마트워치 | 10~30만 |
| 자전거 | 20~80만 |
| 악기 | 20~200만 |
| 명품 가방·시계 | 30만~ |

## 실행 순서 (60분)

**1. 시세 확인 (10분)**
번개장터·중고나라에서 같은 모델을 검색해 **판매 완료** 건 위주로 봅니다.
등록가는 희망가라 참고가 안 됩니다. 실제 팔린 가격의 중간값을 잡으세요.

**2. 사진 (20분)**
중고 거래는 사진이 가격의 절반입니다.
- 자연광, 단색 배경(흰 벽이나 책상)
- 정면·후면·측면·단자부·화면 켠 상태
- **흠집은 반드시 클로즈업으로 포함.** 숨기면 현장에서 깎이거나 취소됩니다.
  미리 공개하면 오히려 신뢰가 올라 정가에 팔립니다.
- 구성품(박스·충전기·보증서) 함께 한 장

**3. 등록 (20분)**
당근마켓과 번개장터에 **동시** 등록하세요. 한 곳만 하면 노출이 반토막입니다.

제목 형식: `⟨모델명 정확히⟩ ⟨용량·연식⟩ ⟨상태⟩`
예) `맥북프로 14 M3 512GB 배터리사이클 120회`

본문에 넣을 것:
- 구입 시기, 사용 빈도
- 하자 유무 (없으면 "없음"이라고 명시)
- 구성품
- 거래 방식과 지역
- **판매 이유** — 한 줄이면 됩니다. 이게 있으면 문의량이 확실히 늘어납니다.

가격은 목표가보다 **5~10% 높게** 걸어두세요. 중고 거래는 네고가 기본이라
정가로 걸면 목표가 아래로 내려갑니다.

**4. 응대 (10분씩 수시)**
- 답장은 빠를수록 좋습니다. 중고 시장은 선착순에 가깝습니다.
- 과한 네고는 그냥 거절하세요. 며칠 안에 정가 구매자가 옵니다.
- 급하면 "오늘 직거래 시 ⟨N⟩만원"을 먼저 제안하세요. 즉시 성사율이 크게 오릅니다.

## 안전

- **직거래 우선.** 택배 거래는 분쟁이 나면 며칠이 날아갑니다.
- 사람 많은 공공장소, 낮 시간. 지하철역·경찰서 앞이 무난합니다.
- 현장에서 작동 확인시키고 **입금 확인 후** 물건을 넘기세요.
- 선입금 유도, 외부 링크, 안전결제 사칭은 전부 사기입니다. 예외 없습니다.
- 고가품은 계좌이체 즉시 잔액을 직접 확인하세요. 입금 확인 문자는 위조됩니다.

## 팔지 말아야 할 것

- **일할 때 쓰는 장비.** 트랙 B로 외주를 따면 그 장비로 작업해야 합니다.
  주 작업 노트북을 팔면 100만원 벌고 다음 건을 못 받습니다.
- 되사려면 더 비싼 것. 계절 지나 다시 살 물건은 손해입니다.
